# aomok-game — غرفة الأبواب العشرة

لعبة ويب ثلاثية الأبعاد. اللاعب في غرفة بـ 10 أبواب ملوّنة، ولكل باب مفتاح بلونه مرمي على الأرض. خلف كل باب رقم أو علامة حسابية. يوجد باب أرضي يقود إلى غرفة ماء فيها بطاقة "= 7"، وفور دخول غرفة الماء يبدأ مؤقّت 5 دقائق. الفوز: تشكيل معادلة قيمتها = 7 من رموز الأبواب المفتوحة قبل انتهاء المؤقّت.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ينتج dist/
npm run preview  # يعاين النسخة المبنية
```

## التحكّم

- WASD أو أسهم لوحة المفاتيح للتحرك
- الفأرة للنظر (انقر داخل الشاشة لتفعيل التحكم)
- E أو نقر للتفاعل (التقاط مفتاح / فتح باب / نزول الفتحة)
- Shift للجري

## التقنيات

- Three.js للرسم ثلاثي الأبعاد + إضاءة + ظلال
- Firebase Realtime Database لتسجيل الجلسات والنتائج
- Vite للبناء

## بنية المشروع

```
src/
  main.js              # نقطة الدخول، شاشة التسجيل
  firebase.js          # تهيئة Firebase + كتابة الجلسات
  equation.js          # توليد الرموز وضمان وجود حلّ = 7
  game/
    game.js            # حلقة اللعبة، التفاعل، الفوز/الخسارة
    scene.js           # المُصيِّر، الكاميرا، الإضاءة الأساسية
    player.js          # تحكّم منظور أول + جسم لاعب مرئي
    room.js            # الغرفة الرئيسية، الأبواب، المفاتيح، الباب الأرضي
    underwater.js      # غرفة الماء + بطاقة "= 7"
    ui.js              # HUD، شريط المعادلة، المؤقّت
    colors.js          # لوحة ألوان الأبواب
    textures.js        # نقوش مولّدة من Canvas
```

## ملاحظة أمنية حول Firebase

مفاتيح `firebaseConfig` للويب مكشوفة بطبيعتها (هي معرّفات وليست أسرارًا). لحماية البيانات، اضبط قواعد قاعدة البيانات في Firebase Console:

```
{
  "rules": {
    "sessions": {
      ".read": false,
      "$room": {
        "$name": {
          "$session": {
            ".write": "newData.exists() && newData.hasChildren(['name','room'])"
          }
        }
      }
    }
  }
}
```
